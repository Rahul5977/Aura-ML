# TROUBLESHOOTING
# ============================================================================
#
# Issue: NumPy version conflict
#   Fix: pip install "numpy>=1.24.0,<2.0.0" --force-reinstall
#
# Issue: OpenCV conflicts
#   Fix: pip install opencv-python-headless (instead of opencv-python)
#
# Issue: spaCy model not found
#   Fix: python -m spacy download en_core_web_sm
#
# Issue: CUDA/GPU not recognized
#   Fix: Install appropriate PyTorch version for your GPU
#        Check: torch.cuda.is_available()
#
# Issue: Out of memory during model loading
#   Fix: Enable bitsandbytes for 8-bit quantization
#        or use memory-efficient models
