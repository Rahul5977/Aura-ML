## 🎯 Quick Reference

### Essential Commands

```bash
# Start backend
docker-compose up --build

# Health check
curl http://localhost:8000/health

# Test audio transcription
docker exec -it ml_proj-backend-1 python test_audio_client.py -u user -p pass -a audio.wav

# Test WebSocket chat
docker exec -it ml_proj-backend-1 python interactive_chat_client.py user pass

# View logs
docker logs ml_proj-backend-1 -f
```

### Essential Endpoints

```
REST API:
- POST   /auth/register        Register user
- POST   /auth/login           Get JWT token
- GET    /auth/me              Current user

WebSocket:
- ws://host/ws/conversations/{id}   Chat
- ws://host/ws/v1/audio             Audio transcription
```

### Essential Files

```
Entry point:     aura-backend/main.py
Audio module:    aura-backend/audio/
Tests:           test_audio_client.py, test_websocket_chat.py
Config:          docker-compose.yml, requirements.txt
```

## 📝 Contributing to Documentation

### When to Add Documentation

- Adding new features
- Changing APIs
- Fixing bugs (update troubleshooting)
- Improving performance (update metrics)

### Documentation Standards

1. **Clear Structure**: Use headings, lists, code blocks
2. **Code Examples**: Show real, working code
3. **Step-by-Step**: Break complex tasks into steps
4. **Troubleshooting**: Add common issues and solutions
5. **Update Index**: Add new docs to this index

### Documentation Checklist

- [ ] Clear purpose and audience
- [ ] Table of contents (if > 2KB)
- [ ] Code examples that work
- [ ] Troubleshooting section
- [ ] Links to related docs
- [ ] Last updated date
